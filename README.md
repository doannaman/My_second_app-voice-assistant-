# Terminal Voice Assistant (My Learning Journey)

This application is a customizable, terminal-based personal voice assistant designed to execute your requested commands efficiently.

## 🚀 Key Features

* **Highly Customizable Triggers:** Unlike rigid assistants with fixed commands, this app allows you to personalize your experience. You can define specific voice phrases and map them to the exact actions you want the assistant to perform.
* **Background Execution:** The application can run seamlessly in the background. You can toggle this feature and manage other preferences directly in the settings menu.

## ⚠️ Current Limitations

* **Language Capability:** At present, the voice recognition engine only supports and processes English requests.
* **Latency** The assistant still spends a long time implementing your request 
## 🗺️ Future Roadmap

* **Multilingual Support:** Expanding the assistant's capability to understand and process multiple languages.
* **Text-Input Mode:** Adding a typing interface for situations where using voice commands is impractical, such as in quiet or public environments.
* **Continuous Optimization:** General architectural improvements and updates to enhance overall performance.
